Employee Training & Adoption Analysis
Independent OCM demonstration using 100 synthetic employee records.
Objective
Measure training completion, paired assessment improvement and technology adoption; identify departments needing support.
Tools
Python, Pandas, Matplotlib and Jupyter Notebook.
Files
- OCM_Training_Analysis.ipynb: analysis, charts and recommendations.
- employee_training.csv: fictional employee dataset.
Run
Install pandas, matplotlib and jupyter. Open the notebook with Jupyter and run all cells. Keep the CSV in the same folder.

No employer data or actual business outcomes are represented. Adoption is a simulated binary indicator; the analysis does not establish causality.
